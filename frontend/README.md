# 씨네로케 프론트엔드 (COMP-01)

React + Vite + TypeScript. Node.js 24 기준.

| 명령 | 설명 |
|---|---|
| `npm install` | 패키지 설치 |
| `npm run dev` | 개발 서버 (http://localhost:5173) |
| `npm run test` | Vitest 테스트 |
| `npm run lint` | 코드 검사 (oxlint) |
| `npm run build` | 타입 검사 + 배포용 빌드 |

## 화면 주소 (SRS 6.1)
